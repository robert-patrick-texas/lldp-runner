0.39.1 acceptance contract

1. Flat-versus-graph comparison tool — complete

tools/flat_graph_compare.py reads one or more discovery.json files, or output directories that contain them, and derives a flat host list from topology_graph alone.

  • Logical systems pair with flat hosts through host_refs; observed systems pair by overlapping names, usable addresses, or MAC addresses. A graph system that merges several flat hosts, or a flat host that the graph splits, is reported once.
  • It compares names, addresses, query targets, display names, classifications, and states, and pairs flat neighbor rows with graph relationships by local and remote interface and protocol. Rows that only repeat another flat host's edge are counted as duplicates.
  • It counts host data that only the flat view carries: system details, ICMP results, the SNMP credential route, collection metrics, tags, classification reasons, first and last seen times, the seed flag, and the classification of systems that were never queried. These are gaps, not disagreements.
  • It prints text, --details, or --json, exits 0 when the views agree, 1 when they disagree, and 2 on unreadable or unsupported input. It reads files only and uses only the Python standard library.

On simulated discoveries run through the coordinator's ingestion path, a clean network agreed completely. A switch reached through two management addresses stayed two flat hosts, the second named only by its IP, while the graph merged them into one system and the flat view repeated every neighbor row. No production discovery.json has been compared yet.

2. Behavior unchanged

No source module under src/lldp_runner/ changed apart from the version. Collection, scheduling, install layouts, setup scripts, outputs, diff, and schemas are the same as in 0.39.0.
