0.38.1 acceptance contract

1. Ty clean — complete

ty check reports no diagnostics under the pinned Ty 0.0.63 (251 at 0.38.0), including no unused-suppression warnings.

  • Annotations that disagreed with the code were corrected: ArgumentParser.error returns NoReturn, Coordinator.workers holds BaseProcess objects, the Gufo session argument builders return dict[str, Any], and retry parameters use the new RetryKind and RetryPool aliases.
  • Narrowing Ty could not follow was restructured without changing behavior: values are bound to locals before isinstance checks, and two comprehensions use assignment expressions.
  • The storage roots and discovery.workers hold the "auto" sentinel until load_config() resolves it, so their declared types stay unions. Use sites that only run after resolution cast to the resolved type.
  • Suppressions use rule-specific # ty: ignore[rule] comments: 22 in source and scripts, 21 in tests. Sixteen replace mypy-style # type: ignore[code] comments that Ty does not honor. The rest mark deliberate dynamic code (int() on SNMP or JSON values inside try/except TypeError, and attributes set on exceptions) and test doubles.

2. Tests strengthened, not relaxed — complete

The suite gained is not None and isinstance assertions where results are used, including checks that resolved storage roots are Path objects. No assertion was removed or weakened. Method replacement in test_seed_order_sampling.py now uses monkeypatch.setattr.

3. Umask-independent script-mode tests — complete

test_operator_scripts.py required the SNMP diagnostics to be exactly 0755 and their notes 0644. Git records only the executable bit. Under the shared umask 0002 documented in docs/INSTALL.md, a fresh clone produced 0775 files and both tests failed. The tests now check that the diagnostics are executable, that the notes are not, and that the source archive preserves each file's actual mode. They pass under both umasks and still fail when a diagnostic loses its executable bit or the notes gain one.

4. Behavior unchanged — complete

No collector, worker, retry, credential, topology, output, diff, watch, or schema logic changed. In the diagnostic scripts, IPv6 scope IDs are now read when len(sockaddr) == 4 instead of >= 4. IPv6 getaddrinfo results are always 4-tuples, so the outcome is the same.

5. Release metadata — complete

The application version is 0.38.1. The constraints manifest moved to constraints/release-0.38.1.txt with identical pins, and the release test now rejects a leftover release-0.38.0.txt. Dependency minimums and exact Linux pins are unchanged.
